# Dentist Interview Coach

A browser-based dental interview practice app with voice and text answers, English and Deutsch prompts, clinical cases, answer feedback, and a versioned reference panel.

## Deploy to Vercel

Import this repository into Vercel as an **Other** framework project. The included `vercel.json` publishes the `dist` directory. There are no required environment variables or build commands.

The CV, interview answers, personal notes, and latest report stay in the user's browser. The reference panel contains short summaries and links; the copyrighted textbook itself is not included.
